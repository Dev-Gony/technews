개인정보처리방침

itgony · GONY DAILY 자동화 · 시행일 2026-11-03

1. 서비스 개요

itgony는 GONY DAILY에 실린 기술 뉴스를 짧은 영상(YouTube Shorts)으로 만들어 운영자 본인의 YouTube 채널에 올리는 개인 자동화 프로그램입니다. 일반 사용자가 로그인하거나 가입하는 서비스가 아닙니다.

2. 사용하는 Google 권한

  • youtube.upload: 운영자 본인 채널에 영상을 업로드하기 위해서만 사용합니다.
  • 다른 사용자의 YouTube 계정, 시청 기록, 구독 정보, 개인 정보에는 접근하지 않습니다.

3. 수집하는 정보

이 프로그램은 방문자나 시청자의 개인정보를 수집하지 않습니다. 운영자 계정의 인증 토큰만 GitHub Actions의 암호화된 Secrets에 보관하며, 업로드 이외의 목적으로 사용하거나 제3자에게 제공하지 않습니다.

4. 보관 및 삭제

인증 토큰은 운영자가 GitHub Secrets에서 삭제하거나 Google 계정의 서드파티 액세스에서 권한을 해제하면 즉시 효력을 잃습니다.

5. 문의
